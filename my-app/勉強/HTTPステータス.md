# HTTPステータスコード

HTTPステータスコードは、ブラウザーやAPIクライアントからのリクエストに対して、サーバーが処理結果を伝えるための3桁の番号です。レスポンスのステータス行や開発者ツールのNetworkタブで確認できます。

## 先頭の数字でわかる分類

| 範囲 | 意味 | 概要 |
|---|---|---|
| 1xx | 情報 | リクエストを受け付け、処理を続けている |
| 2xx | 成功 | リクエストが正常に処理された |
| 3xx | リダイレクト | 別の場所への移動や、キャッシュの利用が必要 |
| 4xx | クライアントエラー | リクエストの内容や認証などに問題がある |
| 5xx | サーバーエラー | リクエストを処理するサーバー側で問題が起きた |

## よく使うステータスコード

### 成功（2xx）

- **200 OK** — 正常に処理された。ページの表示やデータ取得などでよく使う。
- **201 Created** — リソースの作成に成功した。新しいデータの登録など。
- **204 No Content** — 処理は成功したが、レスポンス本文はない。削除や更新の応答など。

### リダイレクト（3xx）

- **301 Moved Permanently** — リソースが恒久的に別のURLへ移動した。
- **302 Found** — 一時的に別のURLへ移動する。ログイン後の画面遷移などで使われる。
- **304 Not Modified** — リソースに変更がないため、ブラウザーのキャッシュを使える。

### クライアントエラー（4xx）

- **400 Bad Request** — リクエストの形式や内容が不正。
- **401 Unauthorized** — 認証が必要、または認証情報が無効。ログインしていない場合など。
- **403 Forbidden** — 認証の有無にかかわらず、その操作を行う権限がない。
- **404 Not Found** — 指定されたページやリソースが見つからない。
- **405 Method Not Allowed** — そのURLでは、指定したHTTPメソッド（GETやPOSTなど）が許可されていない。
- **409 Conflict** — 現在の状態とリクエストが競合している。重複登録など。
- **422 Unprocessable Content** — 形式は正しいが、入力値の検証に失敗した。
- **429 Too Many Requests** — 短時間にリクエストを送りすぎている。

### サーバーエラー（5xx）

- **500 Internal Server Error** — サーバー内部で予期しないエラーが起きた。
- **502 Bad Gateway** — 中継サーバーが、接続先から不正な応答を受け取った。
- **503 Service Unavailable** — メンテナンス中や過負荷などで、一時的に処理できない。

## 401と403の違い

- **401** は「あなたが誰か確認できない／認証が必要」という意味。
- **403** は「あなたが誰かにかかわらず、この操作は許可されていない」という意味。

## 開発時の見方

1. ブラウザーの開発者ツールで **Network** タブを開く。
2. 問題が起きたリクエストを選び、**Status** を確認する。
3. 4xxならURL・HTTPメソッド・送信データ・認証・権限を確認する。
4. 5xxならサーバーのログや、サーバーが呼び出す外部サービスの状態を確認する。

ステータスコードは処理結果の大まかな分類です。具体的な原因は、レスポンス本文やサーバーログもあわせて確認します。また、リクエストが成功したかどうかと、業務上の処理結果（例：検索結果が0件かどうか）は別のものです。
